# LearnWithHistories · assets do logo

- logo.svg: símbolo completo (use em ≥ 40px)
- icon.svg: símbolo simplificado, sem anel e linhas (favicon, < 32px)
- favicon-16/32/48.png
- apple-touch-icon.png (180×180, fundo sólido)
- icon-192.png / icon-512.png (manifest / PWA)
- og-image.png (1200×630, Open Graph / Twitter)

## Next.js (App Router)
Coloque em `app/`: `icon.svg` (renomeie icon.svg), `apple-icon.png` (apple-touch-icon.png), `opengraph-image.png` (og-image.png). O Next gera as tags automaticamente.
Para favicon.ico, converta favicon-32.png + favicon-16.png.

Cores fixas: #1D3D5A, #F4EBDD, #C8924A, #E0A65A, #B37A35 (iguais no tema escuro).
