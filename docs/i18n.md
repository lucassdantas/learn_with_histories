# Traduções da interface (UI)

Isto é sobre os **textos do site** (menus, botões, páginas Sobre/Termos/Privacidade). O texto das
histórias fica no próprio JSON da história — ver [stories.md](stories.md).

## Como funciona

- Arquivos: `src/translations/<pagina>/<idioma>.json`, páginas: `common`, `home`, `stories`, `about`,
  `terms`, `privacy`. Todos os idiomas têm **exatamente as mesmas chaves** (hoje 120).
- Cada JSON é um objeto plano. Prefixos:

  | Prefixo | Onde | Exemplos |
  |---|---|---|
  | `nav.*`, `header.*` | Header/Footer (`common`) | `nav.stories`, `header.speak`, `header.toDark` |
  | `common.*`, `footer.*`, `nf.*` | geral, rodapé, página 404 (`common`) | `common.ad`, `common.cookieSettings`, `nf.title` |
  | `home.*` | Home | `home.title`, `home.benefit1Title` … `benefit3Desc` |
  | `stories.*` | Lista de histórias | `stories.readingLine` (`{l}`, `{n}`), `stories.emptyDesc` (`{q}`) |
  | `reader.*` | Leitura (fica em `stories`) | `reader.show`, `reader.how1` … `how3`, `reader.more` |
  | `about.*` | Sobre | `about.pillar1Title`, `about.feature1` … `feature6` |
  | `terms.*`, `privacy.*` | Páginas legais | `terms.s1Title`/`s1Desc` … `s8`, `privacy.s1` … `s7` |

- `src/config/translations.ts` importa todos e junta por idioma num objeto só.
- Uso nos componentes:

  ```tsx
  const { nativeLanguage } = useLanguage();
  getTranslation(nativeLanguage, 'stories.readingLine', { l: 'inglês', n: 'português' }); // "{l}" e "{n}" são substituídos
  ```

- A UI sempre usa o **`nativeLanguage`** (idioma que o usuário fala).
- Fallback: idioma desconhecido → `en`; chave inexistente → retorna a própria chave (aparece
  `home.title` na tela). Se aparecer uma chave crua no site, falta a tradução.
- `languageNames[uiLang][code]`: nome do idioma **dentro de uma frase**, no idioma da UI
  (`languageNames.pt.en === 'inglês'`).
- `languageOptions`: lista dos idiomas para os `<select>` — nome no próprio idioma (endônimo, nunca
  traduzido: Português/English/Français/Español) e código curto (PT/EN/FR/ES).

## Adicionar/alterar um texto

Adicione a mesma chave nos quatro arquivos (`pt.json`, `en.json`, `fr.json`, `es.json`) da página correspondente.
Textos em francês e espanhol costumam ser ~25% mais longos que em inglês — o layout já aguenta, mas confira no celular.

## Adicionar um idioma novo (ex.: `it`)

O espanhol (`es`) foi adicionado exatamente por este roteiro — use-o como referência.

1. `src/translations/*/it.json` — criar os 6 arquivos (copie de `en.json` e traduza).
2. `src/config/translations.ts` — importar os 6 arquivos e adicionar `it: { ... }` em `translations`;
   adicionar `it` em `languageNames` (e o nome do italiano dentro de cada idioma) e em `languageOptions`.
3. `src/context/LanguageContext.tsx` — adicionar `'it'` em `LANGUAGES` (valores salvos fora dessa lista
   são ignorados).
4. `src/data/stories/*.json` — adicionar `"it"` em `title`, `description` e em cada `content[].text`.
5. `src/components/StructuredData.tsx` — `inLanguage`.
6. Textos que **listam os idiomas**: `about.feature3` (nas traduções de todos os idiomas) e as descrições
   de SEO em `src/app/layout.tsx`, `src/app/stories/page.tsx` e `src/app/stories/[slug]/page.tsx`.
7. Rode o teste de chaves: todos os idiomas precisam ter as mesmas chaves (ver script em
   [stories.md](stories.md) para as histórias).
